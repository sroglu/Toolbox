# Changelog

## [1.0.0] - 2026-07-16
- Initial release: **UI Element Picker** — hold **Ctrl** and hover in Play mode to select and ping
  the topmost uGUI element under the cursor in the Hierarchy. Auto-injected in the editor with a
  **Tools → Toolbox** enable/disable toggle; supports both the legacy Input Manager and the new
  Input System.
